# 欠薪场景 · 无代码模拟脚本

> 原型 0：无代码对话脚本
> 目的：人工走完整个流程，验证问题设计、逻辑顺序、知识引用是否正确
> 测试方式：一个人扮演"用户"，一个人扮演"AI"，按剧本逐轮对话

---

## 流程总览

```
阶段1: 欢迎与边界告知   → 展示免责声明，确认用户理解
阶段2: 自由描述问题     → 用户用自然语言说事
阶段3: 场景识别         → AI判断是否属于欠薪，如果不是则引导
阶段4: 分轮采集事实     → 逐轮追问7大信息模块
阶段5: 事实确认         → 生成摘要，让用户修改/确认
阶段6: 知识检索与输出   → 基于确认事实检索法规，生成报告
阶段7: 结束与转人工     → 风险判断，转人工条件检查
```
