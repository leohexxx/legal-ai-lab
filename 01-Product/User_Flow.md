# 用户流程

## 主流程

```text
进入产品
  → 阅读服务边界与隐私提示
  → 描述问题
  → 识别劳动纠纷子场景
  → 分轮采集关键事实
  → 用户核对并修正事实摘要
  → 生成时间线与证据清单
  → 检索并展示可追溯法律信息
  → 给出分级下一步建议
  → 需要时转人工律师咨询
```

## 关键交互规则

- 每轮只问少量相关问题，解释提问原因。
- 允许用户回答“不知道”并给出补充方法。
- 在生成建议前要求用户确认核心事实。
- 将“用户陈述”“AI 整理”“外部法律依据”清晰分区。
- 用户可以导出、删除或继续补充案情材料。

## 异常分支

- **不属于劳动纠纷：** 说明当前范围并引导到合适的法律领域。
- **信息不足：** 输出缺失项，不给确定性结论。
- **时效可能紧迫：** 提升风险等级并建议尽快咨询专业人士。
- **材料包含敏感信息：** 提醒遮盖并限制保存范围。
- **检索不到可靠依据：** 明确说明无法确认，禁止模型补写来源。
