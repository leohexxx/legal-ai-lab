# 原始数据

存放从官方来源采集的原始文件快照。

## 目录约定

```
raw/
  labor/              劳动法领域原始资料
    laws/             法律原文
    regulations/      行政法规
    judicial/         司法解释
    cases/            案例原文
```

## 管理规则

- 每个文件应保留原始文件名，并附元数据记录（采集日期、来源 URL、内容哈希）。
- 只保存从合法、公开、授权来源获取的文件。
- 受版权保护的材料不得超出合理使用范围。
- 本目录内容不应直接提交 Git，建议使用 `git-lfs` 或外部存储。
