# 数据资产规划

## 三类数据

### 法律法规数据

保存法规正文、条款结构、发布机关、发布日期、生效日期、有效状态、适用地区、来源链接和查询日期。

### 案例数据

保存公开案例的必要字段、事实摘要、争议焦点、裁判理由、结果、来源和适用边界。避免复制无授权的大规模内容。

### 用户 FAQ 数据

来源可以是经授权访谈、产品反馈或人工编写的合成问题。真实用户内容进入研究集前必须获得适当授权并去标识化。

## 数据治理原则

- 来源合法并记录授权或使用依据。
- 遵守版权、网站条款和技术访问规则。
- 不以规避限制的方式抓取数据。
- 个人信息按最小必要原则采集，并提供删除机制。
- 原始数据、加工数据和可发布数据分层保存。
- 每个数据集保留版本、处理过程、质量检查和责任人记录。

## 建议目录约定

每个数据集后续应包含 `README.md`、数据字典、来源清单、许可证或使用说明、处理脚本和质量报告。原始敏感数据不得提交到 Git。
