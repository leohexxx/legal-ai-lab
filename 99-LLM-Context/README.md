> 本文件夹（`99-LLM-Context/`）是面向**其他 AI 模型/智能体**的入职引导包。

## 📂 项目全貌

Legal AI Lab 是一个面向中国用户的**AI 法律助手平台**，首个验证场景是**劳动争议（欠薪纠纷）**。

```
通用法律入口
  → 领域与问题识别
  → 专业领域模块（欠薪）
  → 事实采集与证据梳理
  → 法律检索与规则引用
  → 风险评估与行动方案
  → 必要时转交律师
```
