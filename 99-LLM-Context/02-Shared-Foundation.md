## 1. 项目北极星

**一句话定位**：
> 帮助普通用户把"我遇到了一件法律问题"转化为一份**可核对、可追溯、可执行、可交给律师**的结构化案件材料。

**用户最终得到**：
- 经本人确认的事实摘要
- 按时间排序的关键事件
- 已有/缺失/矛盾/建议补充的证据清单
- 可能适用的法律规则、程序和官方来源
- 期限、管辖、主体和安全风险
- 分优先级的下一步行动方案
- 可以下载或授权转交律师的案件包

**不以什么作为北极星**：对话轮数、生成字数、单次"看起来很专业"的回答、无数据基础的胜率百分比、自动文书。

## 2. 产品架构

```
通用法律入口
  → 领域与问题识别
  → 专业领域模块（当前：欠薪）
  → 引导式事实采集
  → 结构化事实确认（含版本锁定）
  → 案件工作台（总览/事实/时间线/金额/证据/法条/行动）
  → 必要时→ 风险分析与行动方案
  → 必要时→ 律师转交
```

### 6 层产品能力

| 层 | 名称 | 说明 |
|:--:|------|------|
| 1 | 通用法律入口 | 自然语言→领域/地区/目标/紧急程度识别 |
| 2 | 专业领域模块 | 欠薪（第一个样板），后续扩展劳动争议→更多法律领域 |
| 3 | 案件工作台 | 结构化案件展示：事实/时间线/金额/证据/法条/行动 |
| 4 | 可信知识 | 来源白名单 + 知识卡 + 混合检索 + 引用追溯 |
| 5 | 风险分析 | 事实完整度/证据充分度/主体明确度/期限风险/程序状态等 |
| 6 | 律师闭环 | 转交→律师审阅→律师意见→用户沟通 |

## 5. 核心开发原则

### 5.1 数据流原则
```
U01(首页) → U02(隐私) → U03(领域/地区) → U04(采集) → U05(确认) → U06(工作台) → U07(金额) / U08(时间线)
```
- 数据逐页传递，最终统一到 zustand store
- localStorage 实现草稿持久化（刷新不丢数据）
- 事实版本锁定后才进入分析

### 5.2 事实状态机

每个事实（FactItem）有 4 种状态：

| 状态 | 含义 | 前端表现 |
|:----:|------|----------|
| confirmed | 用户明确确认 | 实色标签，可用于分析 |
| pending | 已记录但未确认 | 提示色标签，要求确认 |
| inferred | AI 从上下文推测 | 单独区域，不自动写入已确认 |
| contradiction | 信息冲突 | 警告，阻止确定性结论 |

### 5.3 知识来源优先

- 每条法律结论必须有来源
- 来源必须有：发布机关、条款、有效状态、查询日期
- 失效/地区不符的来源不能作为当前依据
- 模型解释与原文引用必须视觉区分

### 5.4 移动端优先

- 360px 宽度可完整走通主流程
- 不依赖 hover
- 表单字段在键盘上方可见
- 大文件不阻塞界面

### 5.5 隐私与安全

- 不在日志和埋点中记录案情正文
- 分享链接默认关闭，可过期可撤回
- 用户可查看哪些人员访问过案件
- 高风险动作要求二次确认

## 6. AI 协作纪律

| 规则 | 说明 |
|------|------|
| 来源可追溯 | 每个结论都能回溯到原文 |
| 状态不只用颜色 | 可视化必须附带文字说明（WCAG AA） |
| 未确认≠不存在 | 用户回答"不知道"时生成待补任务，不默认为"否" |
| 不擅自计算 | 缺少规则依据的项目不能自动算金额 |
| 不承诺结果 | 不输出无数据基础的胜率 |
| 高风险转人工 | 人身安全/群体事件/重大金额/临近期限 |
| 用户修改 -> 旧分析过期 | 事实修改后标记旧分析失效 |

## 7. 法律知识工程

### 来源白名单层级

| 层级 | 说明 |
|:----:|------|
| P0 | 国家法律法规数据库、全国人大、人社部、最高法司法解释 |
| P1 | 最高法典型案例、人民法院案例库、地方官方材料 |
| P2 | 普通公开裁判文书（不自动提升为一般规则） |
| P3 | 律师文章、媒体、问答（仅用于发现线索，不作为法律依据） |

### 知识卡类型

| 类型 | 文件 | 说明 |
|:----:|------|------|
| 规则卡 | `data/knowledge/labor/rules/rule_*.yaml`（20 张） | 法律规则，条件→效果→例外 |
| 证据卡 | `data/knowledge/labor/evidence/ev_*.yaml`（12 张） | 证据能证明什么、不能证明什么 |
| 程序卡 | `data/knowledge/labor/procedures/proc_*.yaml`（7 张） | 程序路径、条件、材料、期限 |
